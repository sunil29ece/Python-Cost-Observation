# Python Cost Observation and Analysis

A simple Python project for tracking and visualizing sample monthly expenses in CAD.

## Features
- Track expenses by category
- Calculate total and average costs
- Identify highest and lowest expenses
- Save a bar chart to `cost_analysis.png`

## Requirements
Python 3.9 or newer.

## Install
```bash
pip install -r requirements.txt
```

## Run
```bash
python main.py
```

## Expected summary
- Total: $2900.00
- Average: $580.00
- Highest: Rent ($1500.00)
- Lowest: Transport ($200.00)

The script creates `cost_analysis.png` in the current working directory.
